# Mini Store & Productivity Hub
Beginner-friendly React application developed as part of the Skill Nexis Week 2 Full Stack Web Dev internship assignment.

#Features
- Product cards,displaying product information.
- Reusable React components, using props.
- React state for interactive,favorite buttons.
- To-Do application with add & delete functionality.
- Multiple pages, using React Router.
- CSS Modules, for component-level styling.
- Responsive layout, for various screen sizes.

# Technologies Used
- React
- JavaScript
- HTML
- CSS
- React Router
- Vite

# How to Run Locally

1. Clone this repository.
2. Run npm install.
3. Run npm run dev.
4. Open the local URL provided by Vite.
